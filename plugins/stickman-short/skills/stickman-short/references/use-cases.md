# Use cases (what works on Shorts)

| Use case | Hook formula | Beats | Look | Voice tier |
|---|---|---|---|---|
| **History twist** | "A man sold the Eiffel Tower." State the impossible result first. | hook → place + year → the trick → the payoff → twist → CTA | paris / city / room, top hat for the main character, money props | premium or hybrid (storytelling needs emotion) |
| **Motivation** | "Get 1% better every day." A rule or number. | hook → painful start → nobody notices → slow progress → the math → big number reveal → CTA | gym / classroom, headband, `pushup`, `lift`, `chart`, `bigText` | hybrid (Gemini on hook + reveal) |
| **Fight / action** | "Rookie versus the undefeated champion." Underdog vs favourite. | face-off → first hit → knockdown → flashback training → gets up → combo → winner | dojo, two `color`s, crown vs headband, `punch` `kick` `block` `fall`, `pow` + `shake` | budget (short lines, action carries it) |
| **What if (science)** | "What if you jumped into a hole through the Earth?" | question → first effect → extreme number → turn → answer → weird ending → CTA | earth / space / street, `bigText` numbers, `question` | budget |
| **Storytime** | "The waiter says enjoy your meal. I say: you too." Relatable cringe. | setup → the mistake → realisation → consequence → comment CTA | city / room / night, speech bubbles, `sweat` | budget (casual voice) |
| **Psychology tip** | "Can't stop procrastinating? Try the two-minute rule." Problem → named rule. | problem → rule → tiny example → bigger example → why it works → "try it now" | office / classroom board / room | budget |

Tips
- First sentence ≤ 8 words. Never start with "Hi guys" or a channel intro.
- One idea per scene; change the camera or pose every scene.
- End on a question or a "follow for more …" line that matches the series.
- Facts: keep numbers checkable (e.g. 1.01^365 ≈ 37.8; falling through a uniform Earth ≈ 42 min, about 8 km/s at the centre).
